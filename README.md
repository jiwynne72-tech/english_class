# Interactive Quiz Suite 🎯

Welcome to the **Interactive Quiz Suite**! This repository features a collection of fun, interactive web-based quiz games. Every game is hosted right here and can be launched directly from the central `index.html` hub.

---

## 🎮 The Games

Below is an overview of the quiz games included in this suite:

### 1. 💡 General Knowledge Challenge
* **Overview:** A fast-paced trivia quiz testing your knowledge across geography, history, pop culture, and science.
* **Goal:** Answer as many questions correctly in a row to build your streak multiplier!

### 2. 💻 Tech & Coding Trivia
* **Overview:** Designed for devs and tech enthusiasts, this quiz covers web development fundamentals, computer history, and code output prediction.
* **Goal:** Score maximum points by solving timed multiple-choice questions.

### 3. 🎬 Pop Culture & Movie Mania
* **Overview:** From iconic film quotes to famous album covers, test how well you know modern media and entertainment.
* **Goal:** Identify the correct references and aim for a 100% completion badge.

### 4. 🧪 Science & Nature Quest
* **Overview:** Explore questions about the natural world, biology, space, and physics.
* **Goal:** Complete all stages to earn the top rank on the summary screen.

---

## 🚀 How to Play

1. Open `index.html` in any modern web browser (or view via GitHub Pages).
2. Choose a quiz game from the central menu card.
3. Complete the quiz and view your score summary at the end!
